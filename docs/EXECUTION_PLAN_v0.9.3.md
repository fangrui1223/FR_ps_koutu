# v0.9.3 执行记录：未匹配全选与面板增高

日期：2026-09-12。依据用户确认执行；不跳过图片，不增加第二模型。

## 目标与边界

- 无匹配对象或所有候选置信度不足：只接受本次请求明确的 `NO_OBJECT` 响应，全选整个画布，继续后续动作。原来存在搜索选区时也全选画布。
- 匹配成功：保留原有 Top-1、灰度软选区和严格 ROI 处理，不改变模型推理。
- 技术故障：继续沿用自动重启并重试一次、仍失败则报错。输入错误、响应损坏、取消、读取选区失败或推理期间文档改变，不能伪装为未匹配。
- 面板：提高默认停靠/浮动高度和最小高度，保留单一纵向滚动容器，底部留出余量；不覆盖用户整个 Photoshop 工作区。
- 安装：升级为 0.9.3，正式 CCX 与后端安装器同时更新，验证已安装文件，不覆盖已发布的 0.9.2 资产。

## 详细步骤及验收

1. [已完成] 对照截图检查清单尺寸、面板布局、UXP 协调器和图像处理器桥。确认两个入口均需改变，不能只改状态文案。
2. [已完成] UXP 错误响应校验请求 ID；仅捕获 `NO_OBJECT`，通过原有短时提交模态写入无羽化全画布选区。沿用取消和文档一致性保护，不生成/导入白色掩码文件。
3. [已完成] ExtendScript 桥在读取响应后先验证请求 ID，未匹配时直接建立全画布选区，不置入掩码；成功/技术错误路径不变。最终包兼容 v1 错误响应省略 schemaVersion，但拒绝显式不兼容版本。
4. [已完成] 面板显示“未匹配，已全选画布”，不显示虚假提示词评分；动作仍可录入与重放。默认停靠高度 580、浮动高度 600、最小高度 420（UXP 逻辑像素），增加底部可滚动空间。
5. [已完成] 自动测试覆盖未匹配、阈值不足、已有 ROI、取消优先、文档改变、错误码与请求不匹配、连续执行、动作录入、短面板滚动配置。36 项插件测试和纯逻辑套件、15 项 Python 测试、2 项 Native CTest 全部通过。
6. [已完成] Photoshop 实机：5050×5050 QA 副本的 UXP 未匹配全选、正常识别、实际动作录入/重放及后续图层复制通过；安装桥连续成功、两种未匹配、输入错误保护、正常严格 ROI 与后续羽化通过。全选以 255 值像素计数验证；无临时文档/掩码层/通道泄漏。停靠面板按钮完整，展开规则可滚至最后一行。
7. [已完成] 更新使用说明、版本和测试报告；Adobe UDT 打包、官方 CCX 安装及 Windows 后端安装完成。CCX/暂存/安装文件一致；最终后端载荷和两版 Photoshop 桥脚本一致。
8. [发布交付] 测试证据和发布说明已整理，按已有无人值守授权提交源码、推送并创建 v0.9.3 Pre-release；远端发布完成状态以 GitHub Release 及资产校验为准。未验证项目如实列出，不声称全矩阵通过。

## 注意事项

全选是有意的失败后备策略，不代表 SAM 成功找到对象。后续调色/复制等会作用于全图；不保证后续任意 Photoshop 命令永不报错。旧动作参数无需重录即可使用新策略，前提是已更新实际执行的插件及桥脚本。Photoshop 可能记住旧面板尺寸；必要时只调整本插件面板的下边缘，不重置整个工作区。
