## 变更及关键保护

- UXP 面板、动作重放和 ExtendScript 图像处理器桥：仅本次请求明确的 `NO_OBJECT`（无候选或低于阈值）全选整画布并正常返回，不跳过图片、不重试，也不局限于原搜索选区。
- 直接建立无羽化的画布矩形，不分配全白大掩码，不导入掩码，不增加文档切换。正常识别仍使用模型软选区并遵守严格 ROI。
- 取消、文档/图层改变、错误请求 ID、损坏响应、输入错误和技术错误不进入全选分支。正常成功响应的校验未放宽。
- 真实后端的 v1 错误响应没有 `schemaVersion` 字段；兼容缺失字段，但拒绝显式不兼容版本，始终核对请求 ID。该差异在最终打包前发现并补充回归。
- 停靠/浮动推荐高度分别 580/600，最小高度 420（逻辑像素），保留单一纵向滚动和底部 20 像素余量。

## 最终安装版 Photoshop 实测

### UXP 面板及动作

1. 在图像左上角白背景设 `[100,100,300,300]` 搜索范围，提示词 `pants`、阈值 0.50。完成后明确显示“未找到满足阈值的对象，已全选整个画布”。
2. 将结果暂存为 Alpha 通道并读取直方图，255 值像素为 **25,502,500 = 5050×5050**；不是只检查 selection.bounds 的假全选。随后羽化命令成功，测试通道/历史状态恢复。仍为 1 图层、3 通道、2 个打开文档（原图与 QA）。
3. 取消 ROI 后正常识别同一图，得到可见裤子灰度选区，Top-1 **0.906**；没有把所有结果误改为全选。
4. 新建隔离组 `FR-SAM-0.9.3-QA` / 动作 `pants-fallback`。白背景 ROI 下点击“执行并录入动作”，再录入“通过拷贝的图层”。动作仅有插件调用和复制两步，录制完成后停止。
5. 重置 QA 为单层并恢复白背景 ROI，在 Photoshop 动作面板播放整个动作。插件显示“动作完成：未找到满足阈值的对象，已全选整个画布”，随后复制步骤正常执行，产生第二个全画布图层，边界 `[0,0,5050,5050]`，没有错误弹框。这是本轮实际录入/重放，不是仅用 Node 模拟。
6. 加高后的右侧停靠弹出面板完整显示状态、提示词、阈值、两个执行按钮和使用规则入口。忙时取消出现、输入和执行按钮禁用；完成后恢复。展开长规则后可纵向滚动。
