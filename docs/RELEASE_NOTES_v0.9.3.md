# FR SAM 文本选区 v0.9.3 Pre-release

## 变化

- 无匹配对象或置信度不足：全选整个画布并继续本图后续操作，不再抛出未匹配错误，也不重试。即使原先有局部搜索选区，后备也覆盖全画布。
- UXP 面板、已录制动作和图像处理器兼容桥统一上述行为；不增加临时白色掩码、掩码置入或文档切换。
- 面板明确显示“未找到满足阈值的对象，已全选整个画布”，不显示虚假评分。正常识别仍保留 Top-1、软选区和严格 ROI。
- 面板默认停靠高度增加到 580，浮动高度增加到 600，最小高度 420（逻辑像素）；底部留白，内容较多时仍可滚动。
- 只有请求 ID 匹配的明确 `NO_OBJECT` 响应可全选。取消、文档改变、输入错误、显存不足、通信错误和损坏响应不进入后备。

## 升级

安装本版本 Windows 后端和 CCX，然后重启 Photoshop。后端安装器同时更新图像处理器桥脚本；只更新 CCX 不会改变旧桥行为。模型不用重下，既有动作不用重录；修改提示词时仍须更新录入的参数。

如果 Photoshop 记住了较矮的旧面板尺寸，可下拉本插件面板底边；无需重置整个工作区。

## 注意

全选是用户确认的后备，不是识别成功。后续调色、复制、蒙版等将作用于整图；并不保证任意后续动作都不会报错。技术故障仍按现有一次自动重试处理。

测试范围见 `docs/TEST_REPORT_v0.9.3.md`。保持免费、未签名 Pre-release；Photoshop 2025、Windows 10、恰好 16 GB GPU 未做本轮同配置实测。图像与模型不随源码上传。
