# FR SAM 文本选区 v0.9.2 Pre-release

修复运行时配置报错，并补齐安装与批处理可靠性检查。

- 修复旧 CCX 安装副本文件访问权限缺失的问题；增加正式包与实际安装文件的一致性校验，避免“安装成功但仍运行旧文件”。
- 修复图像处理器桥接脚本中的构建注释被 ExtendScript 当成特殊指令引起的语法错误。
- 修复桥接临时层被意外设为剪贴层导致全透明导出，以及复制文档时丢失原选区的问题。
- 修复大图掩码置入居中/缩放导致选区偏移：按完整画布校正坐标，导入失败恢复原选区。
- 改善面板状态显示：状态放在顶部，错误简短中文提示，长详情可展开；运行时禁用重复执行，显示取消按钮。
- 原选区读取失败时停止，防止误在全图搜索；推理期间切换或修改文档后拒绝写入旧结果。
- 修复后端启动重试、长任务空闲退出、原生工作线程清理、父进程检测和日志权限降级。
- 改进 Windows 后端升级：先校验暂存运行时和模型，再切换 Python；配置原子替换，安装后置失败返回非零退出码。

升级顺序：安装后端 EXE，再安装 CCX，重启 Photoshop。若重复安装同版本仍显示旧界面，先从 Creative Cloud 卸载 FR SAM 插件再安装；无需删除模型或重录原有动作参数。

验证：21 项插件 Node 测试、纯逻辑套件、15 项 Python 测试、2 项原生测试通过；安装版后端 20 张真实大图 20/20；1000 次 AlphaProxy HTTP 压力请求通过。最终 CCX 已在 Photoshop 2026 上验证普通图层、智能对象及严格原选区范围。

安装版图像处理器桥接脚本已通过连续三次运行、真正无对象时保留原选区、严格 ROI 及后续羽化命令测试；大图掩码坐标往返和导入失败回滚测试通过。

仍为未签名免费预发布版。未实测 Photoshop 2025、Windows 10、恰好 16 GB GPU；1000 请求压力测试不等于 1000 张真实图片端到端验收。SAM 3.1 不等同于精细 alpha matting，冷启动仍可能超过 8 秒。

已知验证边界：长时间混用外部 COM/ExtendScript 调试后遇到一次 Photoshop 像素读取长期等待，重启后取消及重新运行恢复正常。该旧会话问题未完全定位，不承诺宿主异常时取消可以立即结束。

请从同一发布版本下载两个安装包，并按 SHA256SUMS.txt 校验。完整范围见仓库 docs/TEST_REPORT_v0.9.2.md。
