# FR SAM 文本选区：架构与执行计划

> 版本：0.9.1 Pre-release
>
> 更新日期：2026-09-04
>
> 目标：Windows 10/11、Photoshop 2025/2026、NVIDIA GPU（最低 16 GB）

## 1. 产品结论

项目采用 Adobe Manifest v6 Hybrid UXP 插件加当前用户级 Windows 后端。Photoshop 负责活动图层捕获、动作参数和选区写回；本地后端负责模型生命周期与 SAM 3.1 推理。后端不依赖 ComfyUI 或用户 Python，首次请求按需启动，批次内复用，空闲后退出。

用户侧保留两个入口：

1. 交互面板：修改英文提示词和置信度后生成选区，运行中显示取消按钮。
2. 动作入口：把提示词、阈值、模型 ID 和参数版本保存在 Photoshop 动作步骤中。常规动作、Batch 和 PSJS 使用 UXP 动作；原生图像处理器使用安装器部署的 ExtendScript 兼容动作。

## 2. 冻结范围

| 项目 | v0.9.1 决策 |
|---|---|
| 输入 | 当前活动图层，普通像素层和智能对象 |
| 图层语义 | 读取该层自身像素与透明度，忽略下方合成 |
| 文档模式 | RGB 8 位；其他模式直接报错 |
| 原选区 | 作为严格搜索 ROI，输出不得越界 |
| 提示词 | 仅英文，支持短语及逗号分隔候选，最多 5 个 |
| 候选 | 所有提示词和候选中全局置信度 Top-1 |
| 阈值 | 默认 0.50，范围 0.05–0.95，随动作保存 |
| 输出 | 一次性替换为 0–255 灰度软选区 |
| 无对象 | 保留原选区并抛错，不生成空选区 |
| 技术故障 | 自动重启并重试同一请求一次，仍失败则抛错 |
| 后处理 | 全部交给后续 Photoshop 动作 |
| 日志 | 本地轮转，最多 3 个；不记录提示词、图像、源路径或令牌 |
| 分发 | 免费 CCX 加小型联网 Windows 安装器 |

## 3. 架构

Photoshop Hybrid UXP 插件包含中文面板、Action Recorder、短时捕获模态、模态外推理、短时提交模态，以及最小 x64 原生 Addon。Addon 只管理后端进程、回环认证、健康检查、一次重启重试和空闲退出，不在 Photoshop 进程中加载 CUDA。

后端只绑定 127.0.0.1。每次会话使用随机 256-bit 令牌，图像经受限临时会话目录传输。Validator 拒绝目录逃逸、超过 96 MP、非 RGB8、非法提示词和不匹配模型。Meta 适配器使用官方 SAM 3.1 源码提交 660a5e9e1b8b4c02c0ad97229b88a09a6e4ff5b7，选择全局 Top-1 概率掩码，并在 CPU 侧按活动层透明度和 ROI 严格合成。

图像处理器是宿主兼容特例：Photoshop 2026 的旧 ExtendScript 调度器同步调用纯 UXP 动作时会阻塞首个 Imaging/DOM 操作。因此安装器为 PS 2025/2026 的当前用户脚本目录部署兼容桥。桥只创建一个临时活动层文档用于导出，并在原文档内隐藏置入掩码、载入透明度、删除临时层，减少活动文档切换和可见闪烁。

## 4. 性能和资源

- 最大文档：8000×12000（96 MP）。
- 发布最低显存：16 GB；安装前使用 NVIDIA SMI 预检。
- RTX 5090 目标：4000×6000 热端到端不超过 8 秒；冷启动不计。
- 正式实测：7647×5100 冷启动约 8.15 秒，热请求约 0.88 秒；最终安装版后端连续处理 20 张真实大图为 20/20 成功、总计 65.17 秒；后端 1000 次连续请求全部成功。
- 推理采用低分辨率检测/精炼和 CPU 全尺寸掩码合成，避免 96 MP 全分辨率 CUDA 掩码。

## 5. 安装和发布

Windows 安装器以当前用户权限安装到 LocalAppData。安装时选择引用已有固定哈希模型，或从 Comfy-Org 的固定地址下载并校验。它安装 CPython 3.10.11 embedded、PyTorch 2.10.0+cu128、torchvision 0.25.0+cu128、锁定依赖、官方 SAM 源码和图像处理器桥，随后强制离线运行预检。

CCX 使用正式 ID com.fangrui.sam-selection、名称 FR SAM 文本选区、版本 0.9.1、Photoshop 最低版本 26.0.0。发布资产附带 SHA256SUMS.txt、MIT 许可证、Meta SAM 许可证和第三方通知。当前预发布包未做商业代码签名。

## 6. 验证状态

已通过：

- Python 单元测试 10/10。
- UXP 纯逻辑和协调器测试 10/10。
- Release 原生 Addon 测试 2/2，包括正式运行时启动。
- 独立固定运行时离线预检及真实模型冷/热推理。
- 最终安装版后端对测试文件夹 20 张真实图片的连续模型推理，20/20 成功。
- 1000 次连续本地 HTTP 请求。
- Photoshop 2026 27.10 的普通层、智能对象、严格 ROI、软选区、面板取消、动作录入/重放、Batch、PSJS 和图像处理器连续大图。
- Windows 安装器当前用户安装、模型复用、稳定运行时、自检和卸载数据策略。

预发布限制：

- 当前机器没有 Photoshop 2025、Windows 10 或恰好 16 GB 的 NVIDIA GPU，不能伪造这些同配置实机结果。
- Batch 无对象时 Photoshop 2026 会显示宿主“继续/停止”确认；插件能抛错并保留原选区，但不能替宿主静默选择。
- SAM 3.1 概率掩码能形成软选区，但不是专用 alpha matting，毛发、薄纱和半透明质量取决于模型能力。
- 包未签名，因此用 Pre-release 收集安装与兼容反馈。
