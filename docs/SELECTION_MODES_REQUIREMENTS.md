# 选择模式需求确认记录

日期：2026-09-12。状态：用户已确认，待实现。本次运行时报错修复不包含提前实现此功能。

## 选择模式

- 单个最佳对象：仅保留置信度最高的一个达标对象，保持现有行为。
- 全部匹配对象：合并达到用户置信度阈值的对象，保留灰度软边，适合鞋子、手套等。不根据英文单复数自动切换模式。
- “全部匹配”不是“保证选齐一双”，也不是自动判断主体归属。只识别到一只时返回这一只，不因缺另一只触发全选。

## 动作和批处理兼容

- 模式与提示词、阈值一起录入动作，批处理按动作保存的模式执行，而不是读取面板当前模式。
- 没有模式字段的旧动作默认“单个最佳对象”，升级不得改变已有行为。
- UXP 面板、普通动作及图像处理器兼容桥应使用一致语义。

## 多模特与搜索范围

- 用户大多数图片只有一位模特。
- 少数多模特或存在额外鞋子的图片单独处理：先手动框定主体范围，再选择“全部匹配对象”。
- 正常识别结果严格裁切在原搜索选区内；本阶段不增加自动主体归属判断。

## 失败策略不变

- 一个达标对象都没有（明确 NO_OBJECT）：全选整个画布，继续本张图片后续动作；不重试、不跳过图片。即使原来有局部搜索选区，后备仍是整个画布。
- 有一个或多个达标对象：返回相应模式下的正常选区，不触发全选后备。
- 技术故障：保留现有自动重启重试一次、仍失败报错的规则。配置/输入错误、取消、损坏响应不能冒充 NO_OBJECT。

## 后续实现验收要点

1. 单个模式行为与旧版本一致；旧动作无模式参数时仍可执行。
2. 全部模式合并多个达标对象并保留软边，不包含未达阈值的对象。
3. 模式随两个动作入口录入与重放，不受面板后来修改影响。
4. 多对象正常结果遵守 ROI；零对象全选；只找到一只鞋不全选。
5. 面板明确标注模式含义及不保证成对完整的边界。
