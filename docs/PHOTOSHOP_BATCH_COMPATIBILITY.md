# Photoshop 动作、批处理与图像处理器

> 适用插件：FR SAM 文本选区 0.9.3
>
> 更新日期：2026-09-12

## 两种动作步骤

常规动作面板、文件 > 自动 > 批处理和 PSJS 使用 UXP 动作步骤。Photoshop 原生“图像处理器”使用安装器提供的 ExtendScript 兼容步骤。两个入口对用户都表现为动作，但底层不同；不要把 UXP 步骤直接放进图像处理器，因为 Photoshop 的旧同步调度可能卡在读取活动图层。

## 录制常规 UXP 动作

1. 打开一张有代表性的 RGB 8 位图片并选中要读取的图层。
2. 打开“窗口 > 动作”，新建动作组和动作，点击录制。
3. 打开 FR SAM 文本选区面板，输入英文提示词，例如 pants, trousers，设置阈值 0.50。
4. 点击“执行并录入动作”，等待选区生成。
5. 继续录制“选择并遮住”、创建蒙版、保存、关闭等需要的 Photoshop 命令。
6. 停止录制。

动作步骤保存提示词和阈值；以后改变面板输入不会改变该动作。一次批次的所有图片会使用同一组参数。更换提示词时，修改或重新录制插件动作步骤。

不要把固定图片的“打开”命令录入动作。若动作里有“存储为”，在 Batch 对话框勾选“覆盖动作中的‘存储为’命令”，让 Photoshop 使用目标文件夹和文件命名规则。

## 文件 > 自动 > 批处理

- 播放：选择刚录制的动作组和动作。
- 源：选择文件夹；需要递归时勾选“包含所有子文件夹”。
- 目标：
  - 无：动作自行保存/关闭。
  - 存储并关闭：覆盖原文件，风险较高。
  - 文件夹：保存到单一目标目录。
- 文件命名：第一行下拉框选择“文档名称”，第二行选择扩展名。这样保留原文件名。若存在不同子目录中的同名文件，Photoshop Batch 不会自动保持目录结构，必须加入序列号、使用不同目标目录，或改用图像处理器。
- 错误：选择“由于错误而停止”，输入错误或第二次技术失败时让批次停止。无对象/置信度不足从 0.9.3 起不属于此报错路径，而是全选画布继续当前图片的后续动作。若选“将错误记录到文件”，Photoshop 对真正的错误会继续下一张。

截图中第一行文本框为空、下拉为“无”，第二行手动写 .jpg 的设置不会带入原文件名。正确做法是：删除手写的 .jpg，在第一行右侧下拉选择“文档名称”，第二行右侧选择“扩展名”。左侧文本框只用于固定前缀或后缀，不要把扩展名手写在那里。

历史版本无对象错误可能先显示“插件操作失败”，随后询问继续还是停止。0.9.3 不再为 `NO_OBJECT` 抛错；真正的技术/输入错误仍由 Photoshop 的错误策略控制。

## 文件 > 脚本 > 图像处理器

图像处理器能保留输入子文件夹结构和原文件名，更适合多目录同名文件：

1. 安装后重启 Photoshop。
2. 新建动作并开始录制。
3. 运行“文件 > 脚本 > FR SAM Text Selection Image Processor”。
4. 首次录制输入英文提示词和阈值；成功后停止录制。以后重放不再询问。
5. 打开图像处理器，选择输入目录、输出目录和格式。
6. 勾选“运行动作”，选择刚录制的兼容动作。

桥接脚本只读取活动图层，使用一个临时导出文档，并在原文档内隐藏导入掩码、载入选区后删除临时层。画面仍可能有轻微刷新，但不会像旧方案那样来回显示多个活动文档。

## 失败规则

- 没有匹配对象、置信度不足（`NO_OBJECT`）：不重试，直接全选整个画布，继续本张图片后面的所有动作。不是跳过本图，不是保留局部 ROI，也不是成功识别；面板有明确提示。
- 非 RGB8、不支持输入、原选区读取失败、有效搜索区域为空、返回数据损坏：仍报错，不做全选后备。
- 后端崩溃/通信故障：自动重启并重试一次；仍失败则保留原选区并抛错。
- 面板手动取消：不提交迟到结果并保留原选区。
- 成功：一次性替换当前选区，后续动作继续执行。
